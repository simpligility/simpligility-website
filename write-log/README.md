# Write log

This folder contains resources for maintaining and expanding the page at
[https://simpligility.ca/write-log/](https://simpligility.ca/write-log/).

The `write-log.html` file content is maintained in this repo and simply copied
into the code view of the page in the Wordpress admin interface.

The skill for maintaining the file is located in `../skills/simpligility-write-log/`.

[`STATUS.md`](STATUS.md) tracks deferred work and next steps. It is a living
to-do list, not a historical log: when a task is done, remove it from the file.

This is the companion to the [event log](../event-log/): the event log tracks
public events, while the write log tracks written blog posts and articles. The
two share their structure and conventions, and much of the source research
overlaps, so it is worth doing that research with both pages in mind.
